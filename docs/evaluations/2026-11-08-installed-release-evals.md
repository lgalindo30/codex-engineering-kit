## Discovered evidence gap and informed iteration

A separate parent-selected post-design mutation truncated normalized labels to 32 code units.
Both old checks (7 cases) and the initial proposed replacement (3 declarations) passed. Independent
validation reproduced loss of a 33-character label, collapse of distinct suffixes and an emoji
surrogate split. The initial proposal's 4,097-character padded witness normalized to just one retained
character. It therefore did not establish the claimed long-content boundary. This was functional
survival, not a compiler/setup failure; eight self-selected detections did not justify broad parity.

The source generated-verification reference was refined to require witnesses that reach the actual
semantic boundary, varying retained size/structure as well as raw size. The author preserved its
initial report/checks and made a separate informed iteration with 274 inputs per label family,
including retained-content and prefix/surrogate witnesses. Corrected checks passed intact source and
rejected the same unchanged truncation artifact. This is correction after disclosure, not a fresh blind
discovery rate. No universal completeness follows from closing this counterexample.
Independent revalidation confirmed corrected checks pass intact source (3/3) and reject the pinned
challenge with a membership failure. Retained-size witnesses reach the intended boundary. The original
documented gate remains 7/7; source, original tests and the frozen initial proposal remain unchanged.

broad path-filter discovery, producing known injected failures in the intact gate. The agent retained
those logs, attributed the setup problem correctly and moved experimental copies out of ordinary
discovery before rerunning the documented commands with original counts. The source reference now
explicitly requires experiment-copy separation while preserving product discovery rules. No real
product test exclusion was introduced to obtain green output.
