# Next.js deployment

Apply [shared deployment controls](../../../references/deployment.md) for the selected host.
Verify framework output, the host's adapter, and production start path. Static export cannot serve runtime
mutations; an integrated server application does not imply a separate backend.
For a chosen container deployment, apply [Docker controls](../../../references/docker-deployment.md)
and verify the built Next.js server output and asset serving in that image.
